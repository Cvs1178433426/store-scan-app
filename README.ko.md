# Continuixai Ops

Continuixai Ops는 현장 직원과 관리자를 위한 모바일 우선 운영 업무 플랫폼입니다. 역할 기반 반복 업무, 관리자 감독, 일일 업무 요약, 운영 보고서, 재고 카운트 워크플로를 하나의 애플리케이션에 통합합니다.

주요 영역은 **My Work**, **Team Work**, **Count**, **Reports & History**입니다. 사용자 화면에서 제품 이름은 Continuixai Ops로 통일하며, 기존 기술 경로와 일부 호환성 식별자는 업그레이드 안정성을 위해 유지될 수 있습니다.

개발 및 검증 명령은 영어 README의 Local development 및 Review status 섹션을 참조하십시오.
